# Security policy

Calendar for Obsidian runs a few read-only shell commands on the user's vault
(see [Privacy and how it works](README.md#privacy-and-how-it-works)). If you find
a way to make it run something else, write to a file, read outside the chosen
vault or Obsidian's vault list, or open an unexpected URL, please report it
privately through
[GitHub's private vulnerability reporting](https://github.com/diyar4772/obsidian-calendar-plasmoid/security/advisories/new)
instead of opening a public issue.

Only the latest release is supported with fixes.
